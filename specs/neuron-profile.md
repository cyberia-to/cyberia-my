native ID is mudra's unchanged H(compressed public key). The existing browser
account is an identity-only consumer; it acquires no neuron VM, task key or
second CellId. A UI word/signal/building ID remains content or application data.

fixtures pin the prior mudra 348c46195388ac009667144987511a0e33bdc859 domain output.

readers: canonical body hash, pubkey/address binding and exact ADR-036 signature.

of the native BBG task host or robot registry UI being embedded into this app.
